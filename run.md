### 📦 How to Run the Project

Follow these steps to set up and run the project locally:

---

#### 1. Clone the Repository

```bash
git clone https://github.com/alejoeperez/item-detail-frontend.git
cd item-detail-frontend
```

---

#### 2. Switch to the `develop` Branch

```bash
git checkout develop
```

---

#### 3. Install Node.js (Version 20.14.0)

Download and install Node.js v20.14.0 from the official site:\
👉 https\://nodejs.org/dist/v20.14.0/

Make sure `node` and `npm` are available:

```bash
node -v
# should output: v20.14.0

npm -v
# outputs npm version (e.g., 10.x.x)
```

---

#### 4. Install Dependencies

In the project root directory, run:

```bash
npm install
```

This will download all necessary dependencies listed in `package.json`.

---

#### 5. Run the Project

To start the development server:

```bash
npm run dev
```

Then open your browser at:\
📍 `http://localhost:5173`

---

#### 6. (Optional) Use Visual Studio Code

You can open the project in VS Code to:

- Explore the codebase
- Run terminal commands
- Debug or extend the application

```bash
code .
```

Make sure you have [VS Code](https://code.visualstudio.com/) installed and added to your system path.
